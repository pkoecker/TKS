GAPP – Nachweis der tatsächlich verwendeten Parameter

Der GAPP ist ein standardisierter Nachweis dafür, dass eine EZE mit genau den Parametern betrieben wird, für die sie zertifiziert wurde.

Achtung bei E3/DC: GAPP wird teilweise auch als Abkürzung für „Grid And Plant Protection“ und damit für den Netz- und Anlagenschutz verwendet. International bezeichnet GAPP in diesem Zusammenhang jedoch üblicherweise den „Generic Application Parameter Profile“.
  • Das Einheitenzertifikat bestätigt das zertifizierte Verhalten der EZE.
  • Der GAPP zeigt, dass diese zertifizierten Einstellungen tatsächlich in der Anlage verwendet werden.
  • Dokumentiert werden z. B. Firmwarestand, cos φ, Q(U), P(f), Wirkleistungsgrenzen und Schutzparameter.
  • Damit schließt der GAPP die Lücke zwischen Zertifizierung und realer Feldkonfiguration.
  • Im Rahmen von NELEV und Netzanschlussprozessen ist er ein wichtiger Bestandteil der Compliance-Dokumentation.

GAPP – proof of the actual parameter configuration

The GAPP is a standardized document showing that an EZE is operated with the same parameters under which it was certified.

Note for E3/DC: GAPP is sometimes also used as an abbreviation for “Grid And Plant Protection”, referring to the German Netz- und Anlagenschutz. Internationally, however, GAPP in this context commonly refers to the “Generic Application Parameter Profile”.
  • The unit certificate confirms the certified behavior of the EZE.
  • The GAPP demonstrates that the certified settings are actually used in the installed system.
  • Typical entries include firmware version, cos φ, Q(U), P(f), active power limits and protection settings.
  • It therefore connects certification with the real configuration in the field.
  • Within NELEV and grid connection processes, it is an important part of the compliance documentation.

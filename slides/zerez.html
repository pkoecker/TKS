ZEREZ – zentrale Zertifikate statt PDF-Chaos

ZEREZ steht für „Zentrales Register für Einheiten- und Komponentenzertifikate“ und bündelt Zertifizierungsdaten für netzgekoppelte Energieanlagen an einer zentralen Stelle.

  • Jedes hinterlegte Zertifikat erhält eine eindeutige ZEREZ-ID, über die es im Netzanschlussprozess referenziert werden kann.
  • Netzbetreiber können damit prüfen, welches Gerät zertifiziert ist, welche Normen abgedeckt werden und ob das Zertifikat noch gültig ist.
  • Gespeichert werden unter anderem Komponenten- und Einheitenzertifikate, z. B. für Wechselrichter, Schutzgeräte oder EZA-Regler (Erzeugungsanlagen-Regler).
  • Statt unterschiedliche PDF-Versionen zwischen Hersteller, Installateur und VNB (Verteilnetzbetreiber) auszutauschen, dient ZEREZ als zentrale Referenz.
  • Das reduziert manuellen Prüfaufwand, veraltete Dokumente und Rückfragen im Netzanschlussprozess.

Zertifikat → ZEREZ-ID → zentrale Prüfung durch den Netzbetreiber

ZEREZ – centralized certificates instead of PDF chaos

ZEREZ stands for “Zentrales Register für Einheiten- und Komponentenzertifikate” (Central Register for Unit and Component Certificates) and provides a central source for certification data used in German grid connection processes.

  • Each registered certificate receives a unique ZEREZ ID that can be referenced during grid connection approval.
  • Grid operators can verify which device is certified, which standards are covered and whether the certificate is still valid.
  • The registry contains component and unit certificates, for example for inverters, protection devices or EZA Controllers (Generation Plant Controllers).
  • Instead of exchanging different PDF versions between manufacturers, installers and DSOs (Distribution System Operators), ZEREZ acts as a central reference.
  • This reduces manual verification, outdated documents and clarification requests during the grid connection process.

Certificate → ZEREZ ID → central verification by the grid operator
